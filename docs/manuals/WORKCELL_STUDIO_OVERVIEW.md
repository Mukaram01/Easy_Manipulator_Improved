# Workcell Studio Overview

Workcell Studio is the product surface for creating, editing, validating, and simulating robotic workcell scenes.

## Modes
- **Design**: author scene geometry, layout, and task intent.
- **Plan**: prepare and validate launchable scene packages.
- **Simulate**: run fake-hardware plan/sim workflows in RViz2/MoveIt.
- **Hardware Guarded**: real hardware execution is intentionally guarded and not launched from default Plan & Simulate flows.

## Core workflow
1. New Cell / Existing Scene
2. Canvas Layout
3. Task Intent
4. Generate Scene Package
5. Validate
6. Plan & Simulate
