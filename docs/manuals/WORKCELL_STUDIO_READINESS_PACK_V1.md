# Workcell Studio Readiness Pack v1

Schema: `workcell_studio_readiness_pack/v1`.

This is a **review pack**, not runtime execution. It is **not a safety certificate**. It collects existing offline/fake-hardware-first artifacts into one reviewable folder. Fake-hardware smoke execution, if enabled, must be explicit and guarded.

```yaml
schema: workcell_studio_readiness_pack/v1
source:
  scene_package: ...
  project_name: ...
  created_at: ...
artifacts:
  builder_export_summary: ...
  cell_definition: ...
  environment_layout: ...
  builder_task_intent: ...
  task_recipe: ...
  task_flow_summary: ...
  static_preview:
    svg: ...
    html: ...
    summary: ...
  offline_plan_preview_request: ...
  rviz_moveit_plan_preview_session: ...
  fake_hardware_smoke_launch_report: ...
  planning_scene_readiness_report: ...
results:
  builder_scene_validation: PASS/WARN/FAIL
  task_intent_status: ...
  task_recipe_status: ...
  task_flow_status: ...
  static_preview_status: ...
  offline_plan_preview_status: ...
  rviz_preview_session_status: ...
  smoke_launch_status: ...
  planning_scene_readiness: PASS/WARN/FAIL
  final_readiness: PASS/WARN/FAIL
  classification: ...
safety:
  motion_command_sent: false
  moveit_plan_service_called: false
  runtime_execution_called: false
  real_hardware_enabled: false
  runtime_io_applied: false
  smoke_execute_used: false
summary:
  blockers: []
  warnings: []
  suggested_next_actions: []
```

## HTML dashboard artifact
Readiness packs may include `artifacts.readiness_dashboard` pointing to `readiness_dashboard.html`. The dashboard summarizes readiness, safety flags, static preview, task flow, artifact status, blockers/warnings, and guarded next commands for offline review.
