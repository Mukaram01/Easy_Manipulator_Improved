# Test object visuals

Render-only appearances for the simulated test objects of New Cell > Sorting
(`catalog/workcell_studio_profiles/ur5_2f_workbench.yaml`, `scenarios.multi_bin_sorting_cell.appearances`).
The physics body is always the qualified 25 mm test block; a visual only changes what the simulated camera
renders, and object classes come only from EPD.
