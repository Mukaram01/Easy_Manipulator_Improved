# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing **security@picknik.ai**.
Please include a detailed description and steps to reproduce when possible.

## Supported Versions

We currently support the following ROS 2 distros/branches:

| ROS 2 Distro | Status |
| --- | --- |
| Humble | Supported |
| Jazzy | Experimental |

## Response Expectations & Disclosure

We aim to acknowledge reports within **5 business days** and provide an initial assessment
within **10 business days**. Please allow us time to investigate and address the issue
before public disclosure. We will coordinate a disclosure timeline with the reporter
once a fix or mitigation is available.
